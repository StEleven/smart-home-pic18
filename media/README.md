# 实际项目展示

- [最终展示视频](https://github.com/StEleven/smart-home-pic18/releases/tag/demo-v1.0)：4分55秒，1920×1080、30 fps，H.264 / AAC，约157 MB；在 Release 附件中下载 `smart-home-demo-1080p.mp4`。
- [3D 上位机](host-3d.png)：实际板端联动录屏中的画面，包含温湿度、照度、场景与门控状态。
- [板卡实拍](hardware.jpg)：项目实际板卡与接线照片，PIC18F57Q43 Curiosity Nano 配合 Curiosity Nano Explorer。

视频含实物拍摄、上位机录屏与功能示意动画。动画用于解释系统，不是硬件动作的实测记录；门、窗、风口和窗帘以舵机模拟，灯光、空调和家电由板载灯与显示表示。门窗状态来自软件输出，没有独立位置传感器反馈。

## 来源与许可
